🌐 Cloudflare Tunnel

Đẩy server ra public internet qua Cloudflare. Cần cài cloudflared và có trong PATH.

Quick Tunnel sinh subdomain ngẫu nhiên *.trycloudflare.com, miễn phí, không cần tài khoản Cloudflare. URL đổi mỗi lần khởi động.

Named Tunnel cho phép gắn subdomain trên domain riêng (ví dụ szalo.example.com). Cần authorize cloudflared một lần với Cloudflare account đã add domain.
